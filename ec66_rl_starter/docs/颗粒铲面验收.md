# 静态铲面粗颗粒诊断（2026-09-20）

目的：在装入半锅物料之前，先检查真实铲面分块碰撞能否承接颗粒。此处只用真实铲面的 135 块碰撞盒，保持机械臂初始演示姿态的安装方向，平移到独立试验台。没有运行机械臂关节，也没有反作用力耦合或新的 PPO 训练。接料盘远低于铲面，不参与承料。

## 模型与体积定义

Newton 1.2.1 自带 XPBD 的球形粒子接触，不是 MPM，也不是已经标定的真实物料。未升级 Newton。使用当前 env_isaaclab，但不依赖 Isaac Lab 环境管理器。

- 装载诊断：粒子半径 6 mm，共 1326 颗。
- 假定松装固相体积分数 0.60。名义松装体积 = 球体积总和 / 0.60 = 1.99956 L；这是近似换算，不是落稳表面测得的体积。
- 假定松装密度 1600 kg/m³、接触摩擦 0.6；均未标定，不可直接沿用为 MPM 本构参数。
- 默认 60 Hz、32 子步、8 次迭代、soft_contact_relaxation=0.1，静置 20 秒。不使用人为冻结粒子来通过落稳判断。
- 诊断门槛：保留至少 99%；最后 0.5 秒每帧采样的最大速度均小于 0.05 m/s；最大球间重叠小于半径的 10%；无铲面下方可疑事件。

## 结果与边界

| 测试 | 结果 |
| --- | --- |
| 少量 12 mm 直径颗粒，195 颗 | 全部保留并落稳 |
| 更细 6 mm 直径颗粒，754 颗 | 全部保留并落稳；16 子步、松弛 0.3、4 秒 |
| 约 2 L 等效装载，1326 颗 | 20 秒时保留 1319 颗，99.47%；7 颗未保留 |
| 2 L 测试末段速度 | 最大约 0.0212 m/s，RMS 最大约 0.00092 m/s |
| 2 L 测试最大球间重叠 | 约 0.044 mm |

默认松弛 0.9 的初次密集装载测试持续抖动：16 子步/4 秒末段最大速度约 0.557 m/s；32 子步/10 秒仍约 0.411 m/s。松弛 0.3/6 秒约 0.482 m/s。改为 0.1/32 子步后，12 秒仍有个别颗粒在移动，20 秒通过。失败记录保存在 logs/tool_particles；未将这些结果计为通过。

保留判定使用铲面投影下的高度与粒子位置；铲面下方可疑计数是逐帧采样，不是连续碰撞证明，也可能混入从边缘滑出后绕至底部的轨迹。本轮未记录可疑事件，不等于全铲面、所有粒径都保证不漏。只覆盖中央约 16×18 cm 的投料区域、一个静态安装姿态，没有完整边缘/接缝扫描、动态装载、实际容量测量。99.47% 对应保留约 1.989 L 的名义等效量，尚不满足“每次实际恰好 2 L”的最终计量要求。

报告始终保留 capacity_2l_physically_validated=false。单元测试及无窗口回放已运行，可见 GL 窗口本轮未检查。

## 运行

```powershell
cd C:\newton\ec66_rl_starter
$env:PYTHONPATH = 'C:\newton\ec66_rl_starter\src'
& 'C:\newton\env_isaaclab\Scripts\python.exe' -m ec66_rl.newton_native.tool_particles --require-pass
& 'C:\newton\env_isaaclab\Scripts\python.exe' -m ec66_rl.newton_native.play_tool_particles --viewer gl --device cuda:0
```

回放显示独立铲面碰撞块与颗粒，不显示整臂。20 秒后停止步进。报告及初始/最终粒子快照在 logs/tool_particles。`--require-pass` 会在诊断不合格时返回非零退出码；回放的 `--test` 仅检查程序完整执行，不等同容量通过。
