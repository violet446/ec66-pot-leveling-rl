# 面向 EC66 + Newton 项目的学习路径与资料

目标不是成为强化学习理论研究者，而是能亲手完成一个安全、可解释的机械臂 RL 实验，并知道出问题时该看哪一层。

## 总原则

学习顺序是：**任务接口 -> 小实验 -> 必要理论 -> 更复杂任务**。不要先试图读完一本强化学习教材、推完 PPO 全部公式，或一次学完机器人动力学；那会推迟第一次成功训练。

本项目只需先学会回答五个问题：

1. 策略看到了什么（observation）？
2. 策略输出什么（action）？
3. 什么行为得到高分（reward）？
4. 何时结束并重置（episode / reset）？
5. 训练结束后，网络怎样安全地接入控制器？

## 下载期间：90 分钟入门

### 1. 先建立直觉，30 分钟

看 Hugging Face 的入门视频：[Introduction to Deep Reinforcement Learning](https://www.youtube.com/watch?v=CsuIANBnSq8)。重点看环境、动作、奖励、训练、评估这几个段落，不要求跟着安装它的代码。

看完后，用自己的话描述：

```text
机械臂是 agent 吗？不是。策略网络才是 agent 的决策部分。
Newton 是什么？环境/物理世界。
一次动作后发生什么？Newton 前进一步，产生下一状态与奖励。
```

### 2. 把概念映射到本项目，30 分钟

阅读 [任务接口契约](docs/task_contract.md)，并打开 `src/ec66_rl/reach_contract.py`。逐项找到：

- `build_observation()`：策略的眼睛；
- `action_to_joint_target()`：策略的动作如何变成安全的关节目标；
- `compute_reward()`：我们如何定义“做得好”；
- `succeeded` / `safety_failure`：一次尝试何时结束。

不必理解 Python 的每一行；先能把函数名称与上面的五个问题对应起来。

### 3. 只补需要的机械臂知识，30 分钟

先打开教材原文（免费预印本 PDF，带超链接，7.2 MB）：

- [Modern Robotics 教材 PDF（默认版）](https://hades.mech.northwestern.edu/images/7/7f/MR.pdf)
- [Modern Robotics 教材 PDF（大字号版）](https://hades.mech.northwestern.edu/images/2/2e/MR-largefont-v2.pdf)
- [官方主页](https://hades.mech.northwestern.edu/index.php/Modern_Robotics)（Tablet 版、2-up 版、幻灯片、练习题、勘误、配套代码都在这里）

只读 **Chapter 2（Configuration Space）、Chapter 3（Rigid-Body Motions）、Chapter 4（Forward Kinematics）**，共约 80 页。有视频时优先看这三章的视频（合计约 82 分钟）：

- [Ch.2 播放列表](https://www.youtube.com/playlist?list=PLggLP4f-rq01z8VLqhDC94W2nWpWpZoMj)（27:35）
- [Ch.3 播放列表](https://www.youtube.com/playlist?list=PLggLP4f-rq01NLHOh2vVPPJZ0rxkbVFNc)（40:35），其中 [3.3.1 齐次变换矩阵](https://youtu.be/vlb3P7arbkU)（6:22）最关键
- [Ch.4 播放列表](https://www.youtube.com/playlist?list=PLggLP4f-rq00efLcgMcG1m4k5CKlgRcGh)（13:40）

优先理解：

- **关节角 `q`**：电机/关节现在转到哪里；
- **TCP**：工具中心点，铲斗或夹爪真正执行任务的位置；
- **正运动学（FK）**：由 `q` 算 TCP 位姿；
- **逆运动学（IK）**：由目标 TCP 位姿反求关节姿态；
- **工作空间**：TCP 能安全到达的区域。

第一版 RL 输出关节小增量而不是解 IK，因此先不需要深入雅可比矩阵和动力学。

## 第一周：理解一次 RL 训练

### 需要掌握

- agent、environment、state/observation、action、reward；
- step、episode、reset、成功/失败/超时；
- 训练与回放的区别；
- 连续动作与离散动作的区别（机械臂关节动作是连续的）；
- 为什么训练需要很多并行环境：一次物理试验只产生很少经验，同时跑许多份能更快收集经验。

- [Hugging Face Deep RL Course](https://huggingface.co/learn/deep-rl-course/unit0/introduction)：适合把视频中的直觉补成小练习。

## 第三周：理解 PPO，但不手推公式

本项目使用 RSL-RL 的 PPO。现在只理解下面这段话即可：

> PPO 让当前策略在许多环境中采样“状态、动作、奖励”轨迹，再根据哪些动作带来更高回报更新网络；更新时限制新策略不要与旧策略相差过大，从而提升训练稳定性。

阅读：[Spinning Up 的 PPO 说明](https://spinningup.openai.com/en/latest/algorithms/ppo.html)。只看 **Quick Facts** 和开头的直觉说明即可。PPO 可处理连续动作，这正适合关节目标增量；它是 on-policy 算法，意味着主要依赖当前策略刚采到的经验。

先不要调 `clip_ratio`、学习率、网络层数或损失函数。第一次训练只观察三件事：奖励是否上升、成功率是否上升、机械臂是否稳定。

## 第四周：把框架跑通 ✅ 已完成

已按 [路线图](docs/roadmap.md) 的 Gate 1 运行 Isaac Lab Cartpole，并完成训练、冻结策略回放和策略导出。Cartpole 与 EC66 不相同，但它已经证明当前 PPO、Newton、GPU 和导出链路可用。

推荐阅读：[Isaac Lab 3.0 Quickstart](https://isaac-sim.github.io/IsaacLab/v3.0.0-beta2/source/setup/quickstart.html)。重点是 `train` 命令中的四个概念：

- `--rl_library rsl_rl`：采用的训练库；
- `--task`：环境/任务；
- `--num_envs`：并行环境数量；
- `physics=newton_mjwarp`：物理后端。

## 当前阶段：迁移到 EC66

现在实现 `EC66-Reach-v0`，并且一次只增加一个复杂度：

1. 单环境、无沙、零动作 smoke test；
2. 无沙、固定且可达的目标；
3. 由安全关节姿态经 FK 生成随机目标；
4. 1 → 16 → 64 → 256 个环境逐级向量化；
5. 接入 PPO，完成训练、冻结回放与导出；
6. Reach-v0 成功后才加入料箱、接触与少量粒子。

## 暂时不要学习的内容

这些内容有价值，但会拖慢第一次成功：

- 从零实现 PPO；
- SAC、TD3、Dreamer、离线 RL、模仿学习的横向比较；
- 视觉策略、点云、Transformer；
- 精确沙土材料标定和双向耦合；
- 真机直接在线探索。

在 Reach-v0 跑通以前，遇到问题先回到 observation、action、reward、reset 和物理稳定性这五项检查。
